🚀 ApexPlanet Recruitment Form

A modern, fully interactive multi-step recruitment form built using HTML, CSS, and JavaScript.
This project focuses on clean UI, real-time validation, and smooth user experience.

✨ Features:

🧩 Multi-Step Form
    3-step application process:
    Personal Details
    Professional Info
    Final Submission
    Smooth step transitions with animations
    Progress bar with step indicators
    
✅ Real-Time Validation (No Regex)
    Custom validation logic for:
    Full Name (minimum 2 words)
    Email (basic structure check)
    Phone (10 digits only)
    Experience (0–50 years)
    Portfolio URL (http/https required)
    Cover Letter (min 20 characters)
    
Instant feedback with:
    ✔️ Valid indicators
    ❌ Error messages
    🎨 Advanced UI/UX
    Glassmorphism design
    Animated gradient blobs background
    Interactive mouse glow effect
    Floating labels for inputs
    Smooth transitions and micro-interactions
    
🎉 Extra Features
    Loading animation on submit
    Success screen with animation
    Reset functionality to restart form

    
🛠️ Tech Stack
HTML5 – Structure
CSS – Styling (Glassmorphism, animations, responsive design)
JavaScript – Logic, validation, interactivity
